# GSB Bugfix Task
## 题面
角色从走切换到跑时动作会先抽搐一下，1D 混合节点在阈值点算出的权重不是 0 和 1，参数超过最后一个阈值后直接没有任何片段输出；2D 节点里两个方向参数同时变化时权重和总是大于 1，离参数点更远的片段反而拿到更大权重；重复注册同名节点把旧节点覆盖，参数名写错时返回空字典让上层以为动画正常。animation_blend_tree.py 的 BlendTree 需要实现 add_1d、add_2d 和 evaluate：add_1d 接收节点名、参数名和按阈值递增排列的 (阈值, 片段名) 列表，参数落在两个阈值之间按线性插值分配两个片段的权重，落在两端之外只保留端点片段；add_2d 接收节点名、两个参数名和 (x, y, 片段名) 列表，参数与某个片段坐标重合时该片段权重为 1，否则按到各片段距离平方的倒数加权归一化；evaluate 接收节点名和参数字典，返回片段名到权重的映射，只包含权重为正的片段，权重总和为 1；节点重名、阈值不递增、片段名重复、2D 坐标重复、节点不存在、缺少参数或参数非数字一律按 ValueError 报错。

