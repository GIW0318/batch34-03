# GSB Bugfix Task
## 题面
海面看着像一块会平移的塑料板：波峰高度对不上，陡度调大以后水平位移没有跟着变化，法线永远朝着正上方，光照一条水痕都没有。water_waves.py 要做 Gerstner 波采样：GerstnerWave 按方向、振幅、波长、陡度构造，sample(x, z, t) 返回位移后的三维坐标，normal(x, z, t) 返回单位法线；相位用波数乘传播方向上的投影再减角速度乘时间，水平偏移沿传播方向、大小是振幅乘陡度再乘余弦，竖直方向是振幅乘正弦，深水波速由重力加速度和波数算出。WaterSurface 把多道波叠加，sample 等于基准点加各波偏移之和，height 只取竖直分量，normal 用叠加后的偏导重建并保证朝上。振幅为零时位置不动、法线是 (0,1,0)。波长不大于零、振幅为负、陡度超出零到一，构造时抛 ValueError。

## 运行方式
```bash
python -m pytest tests -q
```
