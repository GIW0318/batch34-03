# GSB Bugfix Task
## 题面
过场动画在低端机上播放时，画面总比声音慢半拍：时间戳没有严格递增的帧也能塞进队列；音频时钟已经走到第三帧，画面还在补第一帧；为了追进度一次跳过好几帧却没有留下记录，事后不知道丢的是哪几帧；没有新帧到达时画面直接黑掉，而不是保持上一帧；重复刷新和丢帧的计数混在一起，排查时看不出丢帧规律。video_frame_pacer.py 的 FramePacer 需要实现 submit、present、stats、reset 和 state。submit 只接受非负且严格递增的 PTS，重复或倒退的提交要报错；present 以音频时钟为基准，取不晚于该时刻的最后一帧，比上次展示的帧新就返回 show 并把中间跳过的下标放进 dropped，仍是同一帧则返回 duplicate，没有任何可用帧时返回 idle；fps 必须是正数，present 的时间参数不能为负；同一个音频时刻连续调用只有第一次推进播放位置，后面的调用都按重复帧处理；stats 分别累计展示、重复和丢弃的数量；reset 清空帧队列与计数，之后可以重新从小时间戳开始提交；state 返回的帧列表和计数快照不能被外部改写。

## 运行方式
```bash
python -m pytest tests -q
```
