# GSB Bugfix Task
## 题面
角色披风的软体模拟最近出现几处硬伤：固定点的顶点每帧还是会被重力拖走一点，披风根部整体下滑；两块布料叠在一起时弹簧列表里出现重复连接，力被算了两遍，布面抖得厉害；质量填 0 的顶点直接把模拟撑爆；阻尼填 1 以后速度瞬间归零，填负数反而越跑越快；时间步为 0 时位置没有变化却也不报错，排查了很久；弹簧两端下标越界时只抛出一个看不懂的异常。deformable_mesh.py 的 MassSpringMesh 需要实现构造函数与 step、positions、velocities、state。构造时记录顶点初始位置，弹簧写成两端下标加静止长度，静止长度必须为正，省略时按初始距离计算，下标必须合法、同一条边不能重复（正反算同一条），质量必须为正，阻尼限制在 0 到 1 之间且不能等于 1，固定点下标必须存在；step 先按胡克定律累加弹簧力，再叠加外力加速度，用半隐式欧拉更新速度，乘上 1 减阻尼后推进位置；固定点的位置与速度始终保持初始值；positions 和 velocities 返回副本。

## 运行方式
```bash
python -m pytest tests -q
```
